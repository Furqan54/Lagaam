# Experiments branch

This branch (`experiments/lagaam-new-features`) is for trying new ideas and features on the Lagaam website.
Nothing here is final, and things may break or get thrown away.

The working, approved version of the site lives on `demo/raftar-3d-theme`. It is also bookmarked with the
tag `lagaam-stable-v1`, so it can always be restored exactly as it is today.

- Try things here, not on the stable branch.
- If an experiment turns out well, move it over to the stable branch on purpose.
- If it does not, delete the branch or go back to the tag. Nothing is lost.
